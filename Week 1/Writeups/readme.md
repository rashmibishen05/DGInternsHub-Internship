# Cybersecurity Lab Writeups

## Week 1 – Lab Setup, Linux and Networking Foundations

### Objective
This folder contains separate writeups documenting the learning process, practical exercises, commands, challenges, and key takeaways from TryHackMe.

### Contents

#### TryHackMe Writeups
Create a separate writeup for each of the following rooms:

1. Search Skills
2. Learning Cyber Security
3. Linux Fundamentals Part 1
4. What is Networking
5. Introductory Networking
6. Networking Concepts
7. Pyramid of Pain
8. Intro to LAN

Each writeup should include:
- Room name and objective
- Concepts learned
- Tasks completed
- Commands or techniques used
- Screenshots of completed tasks, where appropriate
- Challenges faced and how they were resolved
- Key takeaways

Document the key concepts learned if this resource is completed.

### Writeup Format
Use a consistent structure for every writeup:

1. Title
2. Objective
3. Concepts covered
4. Procedure and commands
5. Results and observations
6. Challenges and solutions
7. Key takeaways
8. Evidence of completion

### Learning Outcome
The writeups provide a record of hands-on practice, demonstrate understanding of Linux and networking concepts, and help track progress throughout the cybersecurity internship.

**Tools and Platforms:** TryHackMe, Kali Linux, Windows 11 and free networking learning resources.

**Important:** Document only exercises actually completed. Write explanations in your own words and do not copy other learners' solutions.
