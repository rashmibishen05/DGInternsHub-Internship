# Cybersecurity Fundamentals – Notes

## Week 1 – Lab Setup, Linux and Networking Foundations

### Objective
This folder contains theoretical notes covering the essential concepts required to build a safe cybersecurity home lab and understand Linux and computer networking fundamentals.

### Contents

The notes are organized into separate files for each major topic:

1. **Cybersecurity and CIA Triad**
   - Definition of cybersecurity
   - Confidentiality, Integrity, and Availability
   - Real-world examples

2. **Cybersecurity Roles**
   - SOC Analyst
   - VAPT/Penetration Tester
   - Incident Responder
   - Blue Team and Red Team responsibilities

3. **OSI and TCP/IP Models**
   - Network layers
   - Common protocols
   - Examples of attacks at different layers

4. **Networking Fundamentals**
   - IP address and MAC address
   - DNS and DHCP
   - Ports and common network services
   - Common ports and their security risks

5. **Linux Fundamentals**
   - Linux file system hierarchy
   - File permissions and ownership
   - `chmod`, `chown`, and SUID

6. **Security Terminology**
   - Threat
   - Vulnerability
   - Risk
   - Exploit

7. **Virtual Machine Networking**
   - NAT
   - NAT Network
   - Host-only networking
   - Bridged networking
   - Safe lab isolation

8. **Legal and Ethical Basics**
   - Authorization
   - Scope
   - Rules of Engagement
   - Applicable cybercrime laws

### Learning Outcome
These notes provide a structured understanding of cybersecurity principles, networking, Linux administration, virtualization, and ethical security testing.

### Documentation Guidelines
- Each topic is saved in a separate file.
- Explanations are written in original words.
- Tables and practical examples are included wherever useful.
- Only authorized and legal lab activities are performed.

**Tools Used:** VirtualBox, Kali Linux, Ubuntu Linux, Windows evaluation VM, and free learning resources.
