# Linux Command Cheat Sheet

## Week 1 – Lab Setup, Linux and Networking Foundations

### Objective
This folder contains a Linux command cheat sheet with commonly used commands, their functions, and practical use cases. It serves as a quick reference during Linux practice, networking exercises, and cybersecurity lab activities.

### Contents
- At least 30 Linux commands with explanations and use cases.
- File and directory management commands.
- User and group management commands.
- File permissions and ownership commands.
- Process and network monitoring commands.
- Search, filtering, and troubleshooting commands.
- Cron job and system administration commands.

### Topics Covered
1. Basic Linux commands
2. File and directory operations
3. User and group management
4. Permissions using `chmod` and `chown`
5. Process management using `ps`
6. Network monitoring using `ip` and `ss`
7. Searching using `find` and `grep`
8. DNS troubleshooting using `nslookup` and `dig`
9. Task scheduling using `cron`

### Practical Work
Each command is documented with:
- Command name
- What it does
- When to use it
- Example syntax
- Actual output wherever applicable

### Learning Outcome
This cheat sheet helps build confidence with the Linux command line and provides a quick reference for future cybersecurity and system administration tasks.

**Tools Used:** Ubuntu Linux, Linux Terminal, and other free command-line utilities.

**Note:** Commands and outputs should be tested in the lab environment before submission.
